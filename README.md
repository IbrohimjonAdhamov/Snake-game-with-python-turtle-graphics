# Snake Game with Python Turtle Graphics

A classic Snake game built with Python and the Turtle graphics module.

## Features

- Control the snake with the arrow keys
- Eat food to grow
- Score tracking
- High-score tracking
- Game-over detection

## Requirements

- Python 3
- Turtle graphics
- PyCharm or another Python editor
